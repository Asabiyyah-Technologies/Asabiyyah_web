## 1. Prerequisites

The Asabiyyah corporate website uses a **zero-dependency static architecture**. You do **not** need Node.js, npm, or yarn to build, preview, or maintain this website.

- **Python 3.8 or later** (Verified on Python 3.14.10).
- **Git** (for version control).
- Any modern web browser (Chrome, Edge, Firefox, Safari).

## 3. Quickstart & Local Development

### Step 1: Clone or Navigate to the Repository
```bash
cd AMTIC-001
```

### Step 2: Compile the Static Website
Run the compilation script:
```bash
python build.py
```

Start a lightweight local web server serving the `dist/` directory:

## 4. Making Content & Design Changes

### Updating Corporate Facts or Team Profiles
Edit the JSON files in `src/data/`:
- `src/data/company.json`: Change addresses, phone numbers, or company values.
- `src/data/team.json`: Update team bios, credentials, or monograms.
- `src/data/services.json`: Update practice descriptions or deliverables.
- `src/data/products.json`: Update product features, status badges, or disclaimers.

After modifying any JSON file, re-run:
```bash
python build.py
```
The changes will be compiled into `dist/` across all pages in under 100 milliseconds.

### Modifying Shared Components
Edit the relevant component in `src/components/`:
- Navigation: `src/components/header.py`
- Footer & Legal text: `src/components/footer.py`
- SEO Head / Meta tags / Tailwind config: `src/components/seo.py`
- Contact Form: `src/components/contact_form.py`

Re-run `python build.py` to regenerate all pages with the updated component.

## 5. Testing Edge Functions Locally (Optional)

If you have Node.js and Wrangler installed globally and wish to test Cloudflare Pages Functions locally:
```bash
npx wrangler pages dev dist
```
This runs both the static site from `dist/` and mounts `functions/api/contact.js` at `http://localhost:8788/api/contact`.
*(Note: Not required for regular static content development).*
