# Project Overview: Asabiyyah Technologies Ltd — Corporate Website

## 1. Executive Summary

**Asabiyyah Technologies Ltd** is an African technology company focused on developing practical, robust, and impactful digital solutions for businesses, institutions, and underserved communities.

This project covers the end-to-end research, brand positioning, UX/UI design, software engineering, and production readiness for the official corporate website of Asabiyyah Technologies Ltd. The website serves as the primary digital front door and corporate authority for the company, establishing trust with enterprise clients, institutional partners, investors, and prospective talent across Nigeria, the wider African continent, and international markets.

---

## 2. Core Objectives

1. **Establish Corporate Authority & Credibility:** Delineate Asabiyyah Technologies Ltd clearly as the parent technology and engineering company, distinct from its individual products (such as Dila).
2. **Showcase Engineering & Innovation Capabilities:** Accurately present core technical strengths, including custom software engineering, intelligent systems/AI, process automation, data engineering, digital infrastructure, and offline-first/multilingual technology.
3. **Showcase Product Portfolio & Initiatives:** Present flagship products and research initiatives with verified facts, clear problem-solution context, and current operational status:
   - **Dila:** Community savings and group-management platform.
   - **AMANA SHIELD:** Scam and suspicious-link detection initiative.
   - **ClassGPT-N:** Multilingual, curriculum-grounded AI tutoring initiative.
4. **Introduce Executive Leadership:** Present the verified profiles and technical background of the founding team:
   - **Muhammad Auwal Aliyu** — Chief Executive Officer (CEO)
   - **Sulaiman Sabo** — Chief Technology Officer (CTO)
   - **Mahmud Rabiu Zakariyya** — Chief Operating Officer (COO)
5. **Drive Business & Institutional Enquiries:** Provide clear, low-friction, and secure conversion paths for institutional partnerships, B2B engagements, enterprise solutions, and career inquiries.
6. **Ensure World-Class Technical Quality:** Deliver a secure, highly accessible (WCAG 2.1 AA compliant), lightweight, SEO-optimized, mobile-first website adhering to clean architecture standards.

---

## 3. Working Principles

Throughout all stages of this project, the following core principles govern all decisions, documentation, and code:

1. **Evidence before assumptions:** Every claim, metric, and feature must be grounded in verified company materials.
2. **Accuracy before marketing language:** Technical precision and factual integrity take precedence over promotional fluff.
3. **Design before implementation:** Architectural blueprints and visual/UX layouts must be reviewed and approved prior to frontend development.
4. **Simplicity before unnecessary complexity:** Avoid over-engineering, unneeded frameworks, extraneous microservices, or superfluous state layers.
5. **Security and accessibility from the beginning:** Strict data protection, contact form protection, dependency hygiene, and accessible semantic markup from day one.
6. **Reusable architecture without over-engineering:** Maintainable, modular, component-driven codebase.
7. **Mobile-first responsive design:** Optimized for diverse bandwidth constraints and device viewports prevalent in emerging and global markets.
8. **Production-quality code and documentation:** Clear code commenting, architectural decision records, and thorough maintenance guides.

### Anti-Fabrication Safeguards
Under no circumstances will the project fabricate:
- Clients or customer logos
- Partnerships or affiliations
- Testimonials or quotes
- Certifications or accreditations
- Awards or recognition
- Statistics, metrics, user numbers, or transaction volumes
- Founder biographies or educational degrees
- Office addresses or contact information

All unverified data points are documented in `OPEN_QUESTIONS.md` and represented in designs and code with explicit, neutral placeholders pending client verification.

## 4. Multi-Stage Phased Roadmap

The project is executed in six discrete stages. Each stage is gated by explicit stakeholder approval before proceeding to subsequent work:

| Stage | Name | Description | Key Deliverables | Approval Gate |
| :--- | :--- | :--- | :--- | :--- |
| **Stage 0** | **Project Initialization** | Workspace audit, directory scaffolding, governance logs setup, discovery checklist preparation. | Governance registers, directory tree, Stage 1 discovery briefing. | Explicit client signoff on Stage 0. |
| **Stage 1** | **Corporate Discovery & Evidence Audit** | Collection, analysis, and verification of official company materials and facts. | Discovery audit report, verified entity profile, founder profiles, product fact sheets. | Explicit signoff on verified corporate facts. |
| **Stage 2** | **Brand Strategy & Website Requirements** | Corporate narrative, value proposition, IA, sitemap, content matrix, user journeys. | Information architecture, functional spec, content wireframe outline. | Explicit signoff on strategy & content plan. |
| **Stage 3** | **UX/UI & Visual Identity** | Design tokens, typography, component library specs, responsive wireframes and high-fidelity layouts. | Design system tokens, responsive page mockups/wireframes, UI component specs. | Explicit signoff on visual designs. |
| **Stage 4** | **Website Engineering & Implementation** | Technology stack selection (ADR), component engineering, responsive layout, SEO/meta, contact form integration. | Clean production codebase, component library, metadata, functional forms. | Explicit signoff on code & implementation. |
| **Stage 5** | **QA, Security & Deployment Readiness** | Cross-device testing, accessibility audits, security review, performance optimization, deployment guide. | QA audit report, security checklist, Lighthouse performance scorecards, runbook. | Final production signoff & go-live authorization. |
