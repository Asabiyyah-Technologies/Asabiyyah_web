# DILA refined Asabiyyah-color asset package

This package preserves the DILA deer mark, wordmark, descriptor, tagline and component layouts while applying the exact Asabiyyah design-system color tokens.

## Color application
- Core mark and wordmark: Asabiyyah Navy `#1B2A4A`
- Dark surfaces: Navy Dark `#0D1B3E`
- Tagline and dividers: Gold `#C8A951`
- Reversed marks: White `#FFFFFF`
- Supporting system colors are documented in `brand_tokens_asabiyyah.json`.

The source board does not specify the DILA typeface, so wordmark text remains editable system-font text until the approved font or outlined wordmark is supplied.
